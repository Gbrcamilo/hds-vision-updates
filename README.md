# hds-vision-updates
Apenas binarios publicos de atualizacao do HDS Vision (sem codigo-fonte)

## Versões
`versoes.json` lista as versões publicadas (versão, arquivo, SHA-256, data). Fonte de atualização para a tela Versão do HDS VISION:
`https://raw.githubusercontent.com/Gbrcamilo/hds-vision-updates/main`
Publicar uma versão **não instala** nada: cada unidade só muda quando um admin clica em Instalar.
